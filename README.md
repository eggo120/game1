# Survival Game: The Power Role

You are the hunter. Eliminate all four survivors.

## Controls

| Key | Action |
|-----|--------|
| W / A / S / D | Move |
| Space | Shoot freeze projectile (3s stun) |
| Up Arrow | Drop lingering hazard zone (3s, instant kill on contact) |

Melee contact with a survivor also eliminates them.

## Run

```bash
pip install -r requirements.txt
python main.py
```
